## Models — Shuriken Studio kits (https://shurikenstudio.itch.io/obby-tycoon-tower-defense-3d-models)
Commercial use allowed, no credit, no redistribution of the model files. `.glb`, vertex-coloured, no textures. **Not uploaded yet**: the Studio MCP refuses files outside an approved upload directory (Assistant Settings → MCP Permissions). Staged in `assets/itch/_models/`.

| GDD model | File | Tris | GDD budget |
|---|---|---|---|
| M7 shop kiosk | `lobby-shop-kiosk.glb` | 5,180 | 500 |
| M8 leaderboard stand | `leaderboard-sign.glb` | 940 | 300 |
| M11 daily chest | `low-poly-treasure-chest.glb` | 5,032 | 400 |

All three exceed the G9.4 budgets. They are one-off props (about 11k tris in total), so the overshoot is acceptable for placeholders; do not use these kits for anything repeated (coins, gems, wall segments).
